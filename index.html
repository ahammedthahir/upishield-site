UPIShield: Real-Time UPI Fraud Detection

UPIShield is an educational software project built by a student. It helps a user check a UPI payment before sending money by showing a fraud-risk level for the payment.

What it does

  • Fraud risk scoring: a 1D convolutional neural network (CNN) estimates the risk of a payment and labels it SAFE, CAUTION or HIGH RISK.
  • UPI ID (VPA) verification: checks whether an entered UPI ID exists, using a payment gateway verification API.
  • Phishing pattern warnings: flags suspicious words in UPI IDs such as "refund", "kyc" or "prize".
  • Mobile app: a Flutter app sends the UPI ID and amount to a Python (FastAPI) backend that returns the result.

About this project

UPIShield is a non-commercial academic project. It does not sell products or services and does not charge users. UPIShield itself never holds, receives or transfers money. After showing a risk score, the app can open the user’s own UPI app (such as Google Pay or PhonePe) so the user can choose to pay the recipient there. The payment is made entirely inside that UPI app, using the user’s own bank account and UPI PIN, and is processed by that app and the user’s bank. Payment-gateway APIs are used only to verify that a UPI ID exists.
